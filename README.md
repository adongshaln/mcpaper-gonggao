# Adongcraft 功能手册 1.2.1

适用于 Paper 26.3、Java 25。使用原版可点击的书展示服务器玩法，包含 8 个玩家功能插件的 15 个主题。

- `/gonggao`、`/gg`、`/guide`：打开目录，已经看过的介绍也能回看。
- `/gonggao unread`：只看未读或更新的内容。
- `/gonggao 法杖入门`、`/gonggao staff`：直接打开一项介绍。
- `/gonggao 护盾`：按标题、简介和正文搜索。
- `/gonggao reload`：管理员重新读取内容，无需重启。

目录每页七项，鼠标悬停显示简介，点击进入介绍。正文自动换行分页，底部可返回目录；末页的「看完了」保存阅读状态。书是临时界面，不占背包位置。旧 `/gonggao next` 仍可打开未读目录。

登录成功后只有一条可点击的更新提醒，不自动弹书。兼容 AuthMe，等待登录验证完成后再提醒；读取登录状态失败时不提前弹出。读完的介绍不会再次提醒，正文修改后会重新标记为有更新。阅读记录继续使用原来的 `read.yml`，升级不删除旧记录，写入采用原子替换。

1.2.1 补充六种精英词条说明（爆炸分裂、附着、首领僵尸、伽刚特尔、伪装、繁衍），总计20种。发布时同时更新已存在的 `guide.yml`。

介绍内容在 `plugins/mcpaper-gonggao/guide.yml`，包括法杖、六种魔法、刻印、防具护盾、世界等级、精英怪物、死亡箱经验、追踪、标记、砍树、信息显示、排行榜和容器整理。仅展示当前已启用插件对应的条目。配置有误时保留上一份成功载入的内容。

新插件仍可自带旧格式 `gonggao.yml`，也可以在自己的数据目录提供同名文件；已经由新手册覆盖的插件不重复收录旧文案。内容按 `order` 排序。`config.yml` 可设置是否登录提醒及延迟。

`guide.yml` 首次启动时生成，以后保留管理员修改。更新介绍时编辑该文件后执行 `/gonggao reload`。手册中的 G 键标记与法杖新交互随本次配套客户端和标记插件一同发布。

构建：使用 Java 25 和 Gradle 9.1，执行 `gradle assemble`。产物为 `build/libs/mcpaper-gonggao-1.1.0.jar`。第一次升级插件需完整重启；后续只改文字可使用上面的重载命令。
